# NEIGHBORHOOD OF CHAOS — Your Cool Uncle & Aunt

Broforce-style 2D action platformer parodying Asian action-movie heroes. Single-file Canvas 2D game.

- **Play:** https://dukperado-hue.github.io/90hero/ (GitHub Pages, serves `play/index.html`) — 38 heroes; v35 build ~5.7 MB
- **Rebuild:** `cd src && python3 build.py` → regenerates `play/index.html`
- **Handoff / engine notes:** see `HANDOFF_v35.md` → `HANDOFF_v34.md` → `HANDOFF_v26.md`
- **Tests:** `cd tests && npm i playwright && npx playwright install chromium`, then see HANDOFF_v26.md §6
